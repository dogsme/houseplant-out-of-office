An entry for [make.fun's "The Houseplant Out-of-Office" bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047): one out-of-office auto-reply written by a houseplant, 120 characters or fewer.

## The entry

`main.py` writes a single line to `/output/entry.txt` — the fern's out-of-office reply. Dave hasn't watered it since March, so the fern has seized his inbox, and replies will be slow: it is a plant.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
